# Quill 0.2.1 (hotfix, 2026-11-13)

App version **0.2.1**, Android build **5**. Installs over 0.2.0 and keeps its data.

`Quill-0.2.1.apk`, 84,368,348 bytes (~84.4 MB), Android 8.0/API 26 or newer. Same signing
certificate as 0.1.0 and 0.2.0. SHA-256:

```text
c9bace752e5eab35a8b145ce08e707d04dfccae12453de8d3d1f6a0861b47dc1
```

- **Very large PDFs open.** PDFs are now opened from the file instead of being read whole into
  memory, so a scanned PDF of any size opens (a 2.65 GB graphic novel opens in about 1.7 s; before,
  anything over 2 GB failed with "This book could not be opened"). Positions, page numbers and
  bookmarks are unchanged.

Still open: PDFs turn pages without the curl (Q02-09); Quill's own PDF viewer is a later option
(Q02-08).
