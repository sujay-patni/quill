# Quill 0.2.0

Offline Android reading, released 2026-11-12. App version **0.2.0**, Android build **4**.
Installs over 0.1.0 and keeps its data (same signing certificate).

## What is new

- **Quill's own reading engine for EPUB.** Books open in well under a second, pages turn
  instantly, and the page follows your Moon Reader-style layout. Book-wide page numbers, slider,
  go to page, nested contents, search with the match marked, rolled page curl with held turns.
- **Two ways to read an EPUB:** your layout (default), or "Use the book's own styles", which
  shows the page as the book was designed.
- **Reader options:** separate left/right margins, bold, italic, underline, shadow, font family,
  hyphenation switch, two pages in landscape, auto page turn, swipe-up/down and status-bar tap
  actions, blue-light filter, flip speed, saved themes, settings for one book only.
- **Notes:** select text (with handles), highlight in five colours, notes, bookmarks, copy all
  as text, offline dictionary (WordNet 3.0), tappable links and footnote pop-ups. Bookmarks also
  work in PDFs, comics and EPUBs shown in the book's own styles.
- **Library:** universes, reading orders, saved shelves, "Next" in a series or order.
- **Backup & restore:** one `.quill` file with places, statistics, notes, ratings, shelves,
  settings and chosen covers; automatic daily backups and one before every import, restore and
  reset; restore with a preview, merged or replacing everything; book list as a spreadsheet;
  reset all progress or all statistics.
- **Goodreads:** open a book's Goodreads page from the finish prompt or book information; save
  finished books in Goodreads' import format; read a Goodreads export for ratings and dates.
- **CBR comics** (RAR 4) open, converted once into Quill's cache; covers from the first page.


## Known gaps

- RAR 5 and password-protected CBR files are refused with a message.
- "Include book files" in a backup is not built. A note deleted after a backup returns if that
  backup is merged.
- Goodreads accepting Quill's file is not confirmed against a real import; Goodreads offers apps
  no way to mark books automatically.
- A book's embedded fonts are not used in your layout (they are in "the book's own styles").
- Restoring on a second phone, shelf and start-up timing on a large library, and iOS are not verified.
- The dictionary adds about 19 MB to the app.
